# LP Franquia Sorvetes Jundiá: assets

Imagens, logos e vídeos usados na landing page de franquias (https://franquia.jundia.com.br/), publicada no GreatPages.

Os arquivos são servidos via jsDelivr, fixados por tag de versão:

    https://cdn.jsdelivr.net/gh/BrunoFreitas-V4/jundia-franquia-lp@<tag>/assets/<caminho>

Para trocar um arquivo: suba a alteração, crie uma tag nova (v1.0.1, v1.1.0…) e atualize a tag nos links do HTML.
